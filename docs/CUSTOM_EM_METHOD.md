# Custom EM Algorithm for the Final LPA

The final LPA uses a Gaussian finite-mixture model with profile-specific means and profile- and variable-specific variances. Within-profile covariance matrices are diagonal. For each candidate profile count K=2,...,6 and each of 10 completed MIMIC datasets:

1. Lactate and creatinine are transformed with `log1p`; all six inputs are standardized within that completed dataset.
2. Thirty deterministic starts are generated by one-start Lloyd k-means initializations under the candidate-specific seed.
3. The E-step calculates posterior profile probabilities using diagonal normal densities and a row-wise log-sum-exp calculation.
4. The M-step updates mixture proportions, posterior-weighted means, and posterior-weighted diagonal variances.
5. Variances are bounded below at 0.0025 on the standardized scale; a retained solution touching the floor is ineligible.
6. Iteration stops when absolute log-likelihood change is no greater than `1e-8 * (1 + abs(previous log likelihood))`, with at most 1,000 iterations.
7. The converged start with the largest log likelihood is retained.

Across imputations, centroids are aligned by exhaustive profile-label permutations to a medoid imputation. Full metric definitions and thresholds are in the R1A traceability table. The algorithm is implemented in `R/25_run_inflammatory_metabolic_lpa.R`; the synthetic recovery test embedded in that script can be invoked without clinical data by setting `STAGE8A_SELF_TEST_ONLY=1`.

This implementation is source code, not a claim of a novel statistical method. No third-party LPA package source is vendored.
